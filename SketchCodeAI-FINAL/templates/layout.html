Sketch to Code - Convert hand-drawn wireframes to HTML with AI
About Sketch to Code

Sketch to Code is an AI-powered tool that converts hand-drawn wireframes into HTML/Bootstrap code.

The application uses TensorFlow.js to analyze your sketches and identify UI components like buttons, input fields, and more. It then generates the corresponding HTML and CSS code automatically.

How it works:
  1. Upload your hand-drawn wireframe image
  2. Our AI analyzes the image using a Convolutional Neural Network
  3. The system identifies UI components in your sketch
  4. Bootstrap code is generated for each component
  5. You can preview and download the generated code

This project uses TensorFlow.js, Flask, and Bootstrap.
